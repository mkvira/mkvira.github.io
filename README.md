# Mahmoud Kazemi — personal blog

An English-language personal blog and portfolio built with Jekyll for GitHub Pages.

## Local preview

Install Ruby and Bundler, then run `bundle exec jekyll serve` from this folder. The site will be available at `http://localhost:4000`.

## Publish on GitHub Pages

This is the user site for `mkvira.github.io`; its source repository must be named `mkvira.github.io` under the `mkvira` GitHub account.

1. Push the project to the `main` branch of `https://github.com/mkvira/mkvira.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`, and save.
4. Wait for the Pages deployment to finish. The site will be served at `https://mkvira.github.io`.

Add posts as Markdown files in `_posts/`, named `YYYY-MM-DD-title.md`. Edit `_config.yml` and `index.html` to personalize the site further.
