Today I decided to start working on an idea that’s been bouncing around in my head: an open source agent, built with Laravel, that helps us build web projects more easily and professionally.

I want it to be useful for all kinds of web projects, not locked into one model or one way of working. The idea is to connect it to the API of whichever AI model makes sense, then shape how it works for a particular project from its own dashboard. Different project, different needs, different setup—that should all be configurable without having to bend the whole tool around one fixed workflow.

The thing I keep coming back to is the gap between a general-purpose AI chat and the day-to-day work of actually building a product. A project has its own structure, conventions, and decisions. I’d like this agent to be something we can tune around that context and keep using as the project grows.

There’s no finished product yet. Today, this is an idea and a starting point. I’m going to spend a lot of time exploring it, building it up piece by piece, and seeing how big and useful it can become. For now, I’m excited to get started—and I’ll share more as the idea turns into code.
