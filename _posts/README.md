Write each article as a Markdown file named `YYYY-MM-DD-your-title.md`.

Start the file with front matter like this:

```yaml
---
layout: post
title: "Your article title"
date: 2026-11-09
categories: [Technology]
description: "A short summary for the article page and search results."
---
```

Then write the article in Markdown below the closing `---`.
