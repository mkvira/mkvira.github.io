A couple of WordPress plugins I’ve built to make everyday website tasks a little easier.

WordPress plugin · Internal linking

VT Auto Internal Linker

Adding the same internal links by hand across lots of posts gets repetitive. This plugin lets you set keyword-to-URL rules and adds links automatically when pages are displayed. Your saved post content stays untouched, and you can set limits for how often each link appears.

WordPress plugin · SMS login

Vira SMS Login

I made this for sites where people would rather sign in with a phone number than remember another email and password. Visitors can log in or register with an Iranian mobile number and a one-time code sent through IPPanel. It accepts Persian and Latin digits, limits repeated code requests, and works with or without WooCommerce.
